0002 · Merge on supported cause, not subject

owner support desk proposed reviewed 2026-10-29 · 0 days ago

Context

The component-backed review of #4471 shows distinct parser and form-hint causes inside one ticket. Identical subjects are insufficient evidence that two reports describe the same failure.

Proposed replacement for decision 0001

Read the report body and resolve its tenant, locale, form version and channel. Use sameCause from src/lib/kb/causes.ts as the export’s operational grouping rule. Merge only when evidence supports the same cause. Different subjects can describe the same cause; identical subjects can describe different causes. Unknown tenants and uncertain failures need investigation before merging.
